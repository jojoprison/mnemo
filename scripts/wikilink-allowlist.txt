# Wikilink allowlist — illustrative note names that may live in this public repo.
#
# WHY THIS FILE EXISTS
# mnemo is a plugin about Obsidian, so its docs and skills are full of
# `[[wikilink]]` examples. A blanket ban is impossible; a blanket pass is how two
# links into the maintainer's private vault reached a public PR during the
# v1.2.14 review. So `scripts/lint-skills.py` passes only shapes that cannot name
# a real note — placeholders (`[[{hub_name}]]`, `[[Session — …]]`) and single
# ASCII words (`[[wikilinks]]`) — plus the concrete names listed below.
#
# ADDING AN ENTRY IS A REVIEW DECISION, NOT A FORMALITY
# Before adding a line, answer: would this link resolve in someone else's vault?
#   - No, it is an example invented for the docs        -> add it here.
#   - No, it is a fixture name invented for a test      -> add it here.
#   - Yes, it points at a note I actually keep          -> DO NOT add it.
#     A link into a private vault is dead for every reader and exposes what is
#     in that vault. Describe the fact in the doc instead of linking to it.
#
# One name per line, exactly as it appears between the brackets. Blank lines and
# `#` comments are ignored. Entries are checked for staleness by
# scripts/test-lint-wikilinks.py: a name that no longer appears anywhere in the
# repo must be removed, so this list stays a review surface instead of debris.
